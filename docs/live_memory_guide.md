# دليل الذاكرة الحية لحسابات انتقام السلاطين (Live Memory Structure Guide)

هذا الدليل يشرح هيكلية بيانات الذاكرة الحية (`init_data` / Controllers) المستلمة من خادم لعبة **انتقام السلاطين (`and.onemt.war.ar`)** مباشرة عند تسجيل الدخول (CMD 1000 / Subcmd 1)، مع الإشارة إلى ملف العينة الخام الكامل:
📁 **الملف الخام:** [docs/sample_live_memory.json](file:///e:/intqam-sultan/docs/sample_live_memory.json) (يحتوي على **277 متحكماً** حقيقياً لحساب حقيقي بحجم ~392 كيلوبايت).

---

## 1. كيف تصل الذاكرة الحية إلى البوت؟

عندما يتصل البوت بالبوابة ويرسل حزمة تسجيل الدخول، يرسل الخادم حزمة بيانات ضخمة مقسمة إلى متحكمات (Controllers).
يتم تخزين هذه المتحكمات داخل كائن الاتصال:
```python
# داخل أي كلاس تابع للبوت (مثل CastleBot)
init_data = self.conn.init_data  # قاموس dict يحتوي على 277 متحكم
```
وللحصول على متحكم معين بأمان:
```python
ctrl = self.conn.get_ctrl("treviFountainCtrl")
```

---

## 2. أهم المتحكمات لبناء مهام البوت (Key ROS Controllers)

### 1) معلومات الحساب والأمير (`lordInfoCtrl`)
يحتوي على بيانات الأمير، مستوى القلعة، الذهب، VIP، والقوة العسكرية.
- **الوصول:** `self.conn.get_ctrl("lordInfoCtrl")`
- **أهم الحقول:**
  - `name`: اسم الأمير.
  - `level`: مستوى الأمير (Prince Level).
  - `gold`: كمية الذهب الحقيقية.
  - `vipLevel`: مستوى الـ VIP.
  - `power`: القوة العسكرية الإجمالية للمملكة.
  - `mainCastleLevel`: مستوى القلعة الرئيسي.

---

### 2) المهام اليومية وصناديق النشاط (`everydayTaskCtrl`)
يتحكم في إنجاز المهام اليومية وصناديق النقاط المتدرجة حتى 500 نقطة.
- **الوصول:** `self.conn.get_ctrl("everydayTaskCtrl")`
- **أهم الحقول:**
  - `tomorrowZeroUTC`: موعد تصفير اليوم الجديد بتوقيت UTC.
  - `normalRecord`: سجل تكرارات المهام اليومية المنجزة.
  - `chestRecord`: قائمة الصناديق التي تم استلامها اليوم.
  - `chestReward`: المكافآت المتاحة للصناديق.

---

### 3) مكافأة الميناء وسفن البضائع (`timeRewardCtrl`)
يتحكم في سفن الميناء ومكافآتها الدورية المتجددة.
- **الوصول:** `self.conn.get_ctrl("timeRewardCtrl")`
- **الهيكل:**
  ```json
  {
    "rewardTime": 1729978120,
    "step": 2,
    "isGet": 0
  }
  ```
- **القواعد البرمجية:**
  - `isGet == 0`: بضائع السفينة جاهزة للاستلام فوراً!
  - `isGet == 1`: تم الاستلام، ويجب انتظار العداد `rewardTime`.

---

### 4) نافورة الكنوز (`treviFountainCtrl`)
يتحكم في القرعة والموارد المجانية في نافورة الكنوز.
- **الوصول:** `self.conn.get_ctrl("treviFountainCtrl")`
- **الهيكل والموارد:**
  - `1002`: قمح (Grain/Food)
  - `1003`: خشب (Wood)
  - `1004`: حديد (Iron)
  - `1005`: فضة (Silver)
  - `1006`: فولاذ (Steel)
  - `1027`: بلور (Crystal)
- **القواعد البرمجية:**
  - `multipleTimes == 0`: يوجد سحب مجاني متاح بدون ذهب.

---

### 5) كنز البتراء النادر والفعاليات العربية (`petraRareTreasureCtrl`)
يتحكم في خزائن كنز البتراء النادر الحصري في النسخة العربية (`and.onemt.war.ar`).
- **الوصول:** `self.conn.get_ctrl("petraRareTreasureCtrl")`

---

### 6) المدينة والمباني والموارد (`cityCtrl`)
يحتوي على كافة مباني القلعة، مستوياتها، وإحداثياتها ومستودعات الموارد.
- **الوصول:** `self.conn.get_ctrl("cityCtrl")`
- **أهم العناصر:**
  - `buildings`: قائمة بجميع المباني مع مستوى كل مبنى وحالته (ترقية / خامل).
  - `resources`: كميات القمح والخشب والحديد والفضة في المخازن.

---

### 7) طوابير البناء والعمليات (`queueCtrl`)
يتحكم في طوابير البناء والترقية وأبحاث المعهد.
- **الوصول:** `self.conn.get_ctrl("queueCtrl")`
- **أهم العناصر:**
  - طابور البناء المجاني والمدفوع.
  - وقت انتهاء الترقية لحساب وقت الأمر التالي.

---

### 8) الجيش والتدريب بالثكنات (`armyCtrl`)
يحتوي على أعداد القوات ومستوياتها (مشاة بالثكنة، رماة بميدان الرماية، فرسان بساحة الفرسان، وعربات بمصنع العربات).
- **الوصول:** `self.conn.get_ctrl("armyCtrl")`

---

### 9) الحقيبة والمخزون (`bagCtrl`)
يحتوي على الأدوات، التسريعات، وصناديق الموارد.
- **الوصول:** `self.conn.get_ctrl("bagCtrl")`

---

## 3. طريقة فحص أي متحكم عبر بايثون مباشرة

إذا أردت فحص أي حقل بدقة دون فتح الملف الضخم يدوياً:
```python
import json

with open("docs/sample_live_memory.json", "r", encoding="utf-8") as f:
    memory = json.load(f)

# فحص بيانات الأمير
print(memory.get("lordInfoCtrl"))

# فحص المهام اليومية
print(memory.get("everydayTaskCtrl"))
```
