# 🛡️ سرب التدقيق الهندسي الهجومي (Offensive Engineering Audit Swarm)
### منظومة الوكلاء المستقلة لمراجعة بوتات الألعاب ومطابقة سورس كود اللعبة والذاكرة الحية

---

## 📌 نبذة عن المنظومة
هذه منظومة تدقيق متعددة الوكلاء (Multi-Agent Audit Swarm) مخصصة لمشروع بوت لعبة انتقام السلاطين (`E:\intqam-sultan`). مهمة المنظومة الحصرية هي إجراء تدقيق هندسي مستمر وعميق لمنطق مهام البوت، ومطابقته بدقة متناهية مع سورس كود اللعبة الفعلي المفكوك والذاكرة الحية، لكشف أي انحرافات منطقية أو طلبات شبكية غير مستوفية للشروط قد تتسبب في حظر حسابات القلاع.

---

## 👥 تشكيلة السرب (Roster of Agents)

### 1. الوكلاء الأساسيون (Core Analysts)
1. **المنسق الرئيسي (`orchestrator.md`):** إدارة الدورات، التحكيم، مصفوفات التغطية، وتجميع التقارير.
2. **محلل منطق المهمة (`task_logic_analyst.md`):** تشريح كود المهمة، رسم خريطة التدفق، واستخراج الادعاءات.
3. **محلل سورس اللعبة (`game_source_analyst.md`):** مطابقة دوال اللعبة الرسمية وشروطها في Lua و C#.
4. **محلل الذاكرة الحية (`live_memory_analyst.md`):** فحص صلاحية حقول الذاكرة وتصنيفها واكتشاف فجوات TOCTOU.
5. **محلل الطلبات الشبكية (`network_request_analyst.md`):** تدقيق الحزم والـ Payloads ومصفوفة التحقق قبل الإرسال.
6. **محلل الاعتماديات والتقاطعات (`dependency_analyst.md`):** تتبع مسار المراحل الست وتعاون المهام والموارد المشتركة.

### 2. الوكلاء الخصوم (Adversarial Challengers)
1. **الخصم المنطقي (`challenger_logic.md`):** نقض المنطق الداخلي والبحث عن حالات الانهيار والاستثناءات.
2. **خصم سورس اللعبة (`challenger_source.md`):** إبراز نصوص كود اللعبة الصريحة التي تعارض سلوك البوت.
3. **خصم الذاكرة الحية (`challenger_memory.md`):** إثبات عدم موثوقية الذاكرة وتغير الحالة وفجوات التزامن.
4. **الخصم الشبكي ومكافحة الحظر (`challenger_network.md`):** إثبات مخاطر الحظر ورفض الخادم للحزم غير المستوفية.

## 📜 المعايير والبروتوكولات الحاكمة
- **`arbitration_protocol.md`:** بروتوكول التحكيم وقواعد البت في السجالات بين المحللين والخصوم.
- **`preflight_standard.md`:** معيار التحقق المسبق قبل إرسال أي حزمة شبكية، وتصنيف الذاكرة الخماسي (`Valid`, `Stale`, `Missing`, `Invalid`, `Unknown`).
- **`audit_lifecycle.md`:** دليل دورات التدقيق (`audit_XXX`)، سجل التغطية، واستئناف العمل بعد الانقطاع.

---

## 🔒 قيود الصلاحيات الصارمة (Strict Read-Only Enforcement)
- **وضع القراءة فقط المطبق:**
  - قراءة سورس كود اللعبة (`game_file/`).
  - قراءة كود البوت (`tasks/`, `core/`, `database/`).
- **نطاق الكتابة المسموح:**
  - مجلد التقارير: `reports/audit_XXX/`.
  - مجلد تعريفات السرب: `.agents/audit_swarm/`.
- **المحظورات المطلقة:**
  - يُحظر منعاً باتاً تعديل أي ملف كود في البوت.
  - يُحظر منعاً باتاً إرسال أي طلبات شبكية حقيقية لخوادم اللعبة.
  - يُحظر تشغيل أي عمليات تغير حالة القلاع أو الذاكرة الحية.
